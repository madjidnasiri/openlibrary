📚 Open Library

Complete Library Management System for Odoo

Version 1.0.0 LGPL-3 Community & Enterprise

📖 Overview

Open Library is a professional library management module for Odoo 19 that helps libraries, schools, universities, and organizations manage their book collections, members, and lending operations efficiently. The module provides a complete workflow from book acquisition to member registration and lending tracking.

✨ Key Features

📚 Book Management

  • Multi-library support
  • Multi-repository support
  • Book and author management
  • Book editions tracking
  • Publisher management
  • Tags & genres categorization
  • Unique book copy codes

👥 Member Management

  • Member registration
  • Membership tracking
  • Automatic age calculation
  • Member status management
  • Contact integration
  • Multi-library memberships

🔄 Lending Operations

  • Easy book borrowing
  • Automatic due date calculation
  • Return processing with late fees
  • Configurable delay thresholds
  • Complete lending history
  • Real-time status tracking

📊 Views & Dashboards

  • List, Kanban & Calendar views
  • Advanced search filters
  • Detailed form views
  • Comprehensive reports
  • Activity tracking

🔧 Technical Features

  • Multi-company support
  • Granular security groups

🌍 Languages

🚀 Installation

Prerequisites

  • Odoo 19.0 (Community or Enterprise)
  • Python 3.10 or higher

Installation Steps

  1. Copy the module to your addons directory:
    2. cp -r openlibrary /path/to/odoo/addons/
  2. Update the module list in Odoo (Apps → Update Modules List)
  3. Search for "Open Library" and click Install

Demo Data Installation

odoo-bin -c odoo.conf -d your_database -i openlibrary --demo=all

⚙️ Configuration

After installation, configure the module:

  1. Go to Settings → Open Library → Settings
  2. Configure delay thresholds:
    • Warning Delay Threshold: Days after which a book is considered "Delayed" (default: 3)
    • Suspicious Delay Threshold: Days after which status becomes "Suspicious" (default: 30)
  3. Assign user groups to your staff members

📖 Usage Guide

📕 Adding Books

  1. Go to Open Library → Books
  2. Click Create
  3. Fill in book information (Title, Author, Publisher, ISBN, Tags, Summary)
  4. Save the record

📝 Registering Members

  1. Go to Open Library → Subscribers
  2. Click Create
  3. Enter member information (Name, Birthday, Contact details)
  4. Save the record (age is automatically calculated)

🔄 Processing Lending

  1. Go to Open Library → Lending
  2. Click Lend
  3. Select book copy and subscriber
  4. Due date is automatically calculated based on member's allowed days
  5. Click Confirm

📬 Processing Returns

  1. Go to Open Library → Lending
  2. Find the active lend record
  3. Click Return
  4. The system automatically calculates delay days and updates book status
